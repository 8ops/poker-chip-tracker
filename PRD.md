# 棋牌筹码记录器 PRD

## 1. 产品概述

### 1.1 产品名称

棋牌筹码记录器（Poker Chip Recorder）

### 1.2 产品背景

针对线下多人棋牌娱乐过程中，筹码变化依赖人工记录，容易出现计算错误、遗漏、无法追踪历史的问题，设计一个基于浏览器的多人实时筹码记录系统。

解决问题：

-   多人同时参与牌局时无法同步记录
-   每局结束后人工计算容易出错
-   无法快速查看个人累计输赢
-   牌局结束后缺少完整归档

### 1.3 产品目标

核心目标：

-   创建多人共享棋牌记录房间
-   实时记录每局筹码变化
-   自动校验筹码增减平衡
-   自动统计成员累计筹码
-   保存完整牌局历史

成功指标：

-   支持多人浏览器同时进入同一房间
-   每局筹码记录准确率100%
-   历史记录可完整查询

# 3. 使用场景

## 场景1：创建棋牌房间

用户： 房主

操作：

1.  打开网页控制台
2.  点击创建房间
3.  系统生成唯一房间号

输入：

房间名称（可选）

系统处理：

-   创建房间数据
-   初始化房间状态 OPEN

输出：

生成房间号。

------------------------------------------------------------------------

## 场景2：加入房间

用户：

普通成员

操作：

1.  输入房间号
2.  点击加入

系统处理：

-   校验房间存在
-   校验房间状态

输出：

进入共享控制台。

------------------------------------------------------------------------

## 场景3：记录每局筹码

用户：

房间成员

操作：

输入每个成员本局筹码变化。

系统处理：

计算所有变化总和。

规则：

SUM(所有成员变化)=0

输出：

保存本局记录。

# 4. 功能需求

# 模块一：房间管理

## 功能点1：创建房间

### 功能描述

创建多人共享棋牌记录空间。

### 用户操作流程

1.  点击创建房间
2.  输入房间名称
3.  获取房间号

### 系统行为

1.  生成唯一room_code
2.  保存房间信息
3.  初始化状态OPEN

### 数据要求

  字段         类型       说明          必填
  ------------ ---------- ------------- ------
  id           UUID       房间ID        是
  room_code    string     房间编号      是
  name         string     名称          否
  status       string     OPEN/CLOSED   是
  created_at   datetime   创建时间      是

------------------------------------------------------------------------

## 功能点2：关闭房间

关闭后：

允许：

-   查看历史
-   查看统计

禁止：

-   新增成员
-   修改筹码

------------------------------------------------------------------------

# 模块二：成员管理

## 功能点：添加成员

### 数据结构

  字段           类型     说明       必填
  -------------- -------- ---------- ------
  id             UUID     成员ID     是
  room_id        UUID     房间ID     是
  name           string   成员名称   是
  initial_chip   int      初始筹码   是
  current_chip   int      当前筹码   是

------------------------------------------------------------------------

# 模块三：牌局记录

## 功能点：新增一局

数据：

  字段       类型   说明
  ---------- ------ --------
  id         UUID   牌局ID
  room_id    UUID   房间
  round_no   int    局编号

------------------------------------------------------------------------

## 功能点：添加筹码变化

输入：

  字段            类型   说明
  --------------- ------ ----------
  player_id       UUID   成员
  change_amount   int    变化数量

系统校验：

change_amount总和必须为0。

失败：

返回：

筹码未平衡。

------------------------------------------------------------------------

# 模块四：统计分析

功能：

实时计算：

-   当前筹码
-   输赢排名
-   总变化

展示：

-   成员卡片
-   柱状图
-   明细列表

------------------------------------------------------------------------

# 模块五：历史归档

关闭房间后保存：

-   矩形统计图

# 7. API接口设计

## 创建房间

POST /api/rooms

请求：

``` json
{
"name":"周末棋牌"
}
```

响应：

``` json
{
"roomCode":"POKER001"
}
```

------------------------------------------------------------------------

## 加入房间

POST /api/rooms/{code}/join

------------------------------------------------------------------------

## 添加成员

POST /api/players

------------------------------------------------------------------------

## 提交一局

POST /api/rounds/{id}/records

错误码：

  错误码   说明
  -------- ------------
  400      参数错误
  403      房间已关闭
  409      筹码不平衡
  500      服务器异常
